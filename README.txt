# ElectroHub — Electronics Store Website

A responsive front-end electronics store built with plain HTML, CSS and JavaScript.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge/Firefox.
3. No server is required for the demo.

## Included
- Responsive desktop/mobile design
- Hero section and category browsing
- Product filtering
- Search
- Shopping cart drawer
- Deal countdown
- Newsletter form
- Modern footer
- No framework required

## For a real store
Connect the product data to a backend/database and replace the demo checkout with Stripe/PayPal or another payment provider. Add real product images, authentication, order management, inventory and shipping logic.
